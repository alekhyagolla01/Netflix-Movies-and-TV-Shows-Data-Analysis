
<h1 align="center">Netflix Movies and TV Shows Data Analysis</h1>

<h3>Project Overview</h3>
<p>
This project focuses on analyzing Netflix Movies and TV Shows data using Python.
The main objective is to explore Netflix content, identify trends, and gain
insights through data analysis and visualization.
</p>

<h3>Objectives</h3>
<ul>
  <li>Analyze Movies and TV Shows distribution.</li>
  <li>Explore content release trends by year.</li>
  <li>Identify the top 10 countries producing Netflix content.</li>
  <li>Analyze content ratings and popular genres.</li>
  <li>Explore Netflix content added over time.</li>
  <li>Identify top 10 directors.</li>
  <li>Analyze movie duration distribution.</li>
</ul>

<h3>Work Performed</h3>
<ul>
  <li>Loaded and explored the Netflix dataset using Pandas.</li>
  <li>Checked dataset dimensions, columns, and missing values.</li>
  <li>Performed data cleaning and handled missing values.</li>
  <li>Conducted Exploratory Data Analysis (EDA).</li>
  <li>Compared Movies and TV Shows.</li>
  <li>Analyzed country-wise content distribution.</li>
  <li>Analyzed ratings, genres, release years, and directors.</li>
  <li>Created charts and graphs to visualize insights.</li>
</ul>

<h3>Technologies Used</h3>
<ul>
  <li>Python</li>
  <li>Pandas</li>
  <li>NumPy</li>
  <li>Matplotlib</li>
  <li>Seaborn</li>
  <li>Jupyter Notebook</li>
</ul>

<h3>Visualizations</h3>
<ul>
  <li>Movies vs TV Shows Count Plot</li>
  <li>Content Release Year Analysis</li>
  <li>Top 10 Countries Bar Chart</li>
  <li>Content Ratings Distribution</li>
  <li>Top 10 Genres Analysis</li>
  <li>Top 10 Directors Analysis</li>
  <li>Movie Duration Histogram</li>
</ul>

<h3>Project Outcome</h3>
<p>
Successfully explored and analyzed Netflix content data using Python.
Identified trends and patterns in content distribution, genres, ratings,
countries, directors, and movie durations through data visualization.
</p>
